# Пример: сканирование FM диапазона 70-110 МГц

Этот пример показывает прикладное использование библиотеки для обнаружения FM-станций по уровню мощности спектра.

## Что делает сценарий

- Настраивает устройство на `Fs = 10 МГц`
- Сканирует диапазон `70-110 МГц` с перестройкой центра
- Для каждого окна считает спектральную мощность (FFT)
- Ищет локальные пики и выводит частоты обнаруженных станций
- Учитывает подавление DC/LO артефакта (`--f-dc-reject-khz`)

## Рекомендуемая команда запуска

```powershell
dotnet run --project .\Tests\MathCore.HackRF.ConsoleTests\MathCore.HackRF.ConsoleTests.csproj -c Debug -- --mode fmscan --f-start-mhz 70 --f-stop-mhz 110 --f-step-mhz 1 --f-bin-khz 25 --f-threshold-db 7 --f-blocks 12 --f-lna 32 --f-vga 16 --f-dc-reject-khz 250 --queue 256
```

## Параметры

- `--f-start-mhz`, `--f-stop-mhz`: границы диапазона
- `--f-step-mhz`: шаг перестройки центральной частоты
- `--f-bin-khz`: шаг частотной сетки детектора
- `--f-threshold-db`: превышение над шумовым полом для детекции
- `--f-blocks`: количество блоков на одну центральную частоту
- `--f-lna`, `--f-vga`: усиления приёма
- `--f-dc-reject-khz`: ширина подавления около DC/LO артефакта

## Пример результатов из реального прогона

Стенд: HackRF One, LNA=32 дБ, VGA=16 дБ.

Обнаружены частоты, близкие к наблюдаемым в SDR#:

- `97.200 МГц`
- `98.825 МГц` (около `98.8`)
- `100.475 МГц` (около `100.5`)
- `101.800 МГц`
- `102.500 МГц`
- `102.975 МГц` (около `103.0`)
- `104.200 МГц`

Также выявлен участок сильных помех:

- `99.650-100.050 МГц`

## Примечания

- Для более устойчивой детекции слабых станций уменьшайте `--f-step-mhz` и увеличивайте `--f-blocks`.
- Для уменьшения ложных срабатываний увеличивайте `--f-threshold-db`.
- Если в списке видны периодические артефакты около частот перестройки, увеличьте `--f-dc-reject-khz`.
